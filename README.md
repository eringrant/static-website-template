# Simple Academic/Organization Website Template

A minimal Eleventy (11ty) static site template for academic and organizational websites.

## Quick Start

1. **Use this template** - Click "Use this template" on GitHub
2. **Install dependencies** - `npm install` (sets up pre-commit automatically)
3. **Customize** - Edit `src/_data/site.yaml` with your info
4. **Develop** - `npm run serve` (site at `http://localhost:8080`)
5. **Deploy** - Follow GitHub Pages steps below

## Deploy to GitHub Pages

1. Push your changes to GitHub
2. Go to repository **Settings > Pages**
3. Select **"GitHub Actions"** as source
4. Your site will be live at `https://yourusername.github.io/repository-name`
